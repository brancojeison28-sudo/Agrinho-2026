# Agrinho-2026
🌾 Ciclo Vivo — Agrinho Paraná 2026
Sobre o Projeto
Ciclo Vivo é um site educativo desenvolvido para o Agrinho Paraná 2026. Seu objetivo é mostrar a conexão entre campo, tecnologia e natureza, destacando como esses três elementos dependem uns dos outros para construir um futuro sustentável.

A proposta combina conteúdo informativo, identidade visual própria e recursos de acessibilidade, permitindo que mais pessoas possam aprender e navegar pelo site com facilidade.

Conceito e Identidade Visual
O principal elemento visual do projeto é um anel SVG animado presente na página inicial. Ele possui três nós representando:

🌾 Campo
⚙️ Tecnologia
🌿 Natureza

Os elementos giram continuamente, simbolizando um ciclo de cooperação e equilíbrio. Essa escolha reforça visualmente a mensagem central do trabalho: o desenvolvimento sustentável acontece quando produção, inovação e preservação caminham juntos.

Acessibilidade
A acessibilidade foi tratada como parte essencial do projeto.

🌙 Modo Escuro
Alternância entre tema claro e escuro.
Preferência salva automaticamente com LocalStorage.
Compatível com prefers-color-scheme.
Uso de aria-pressed para leitores de tela.

🔠 Controle de Fonte
Quatro níveis de tamanho: Small, Medium, Large e XLarge.
Botões são desabilitados nos limites mínimo e máximo.
Feedback acessível por atributos ARIA.

🔊 Leitura em Voz Alta
Utiliza a Web Speech API nativa do navegador.
Lê todo o conteúdo em português brasileiro.
Rola automaticamente pelas seções.
Destaca visualmente a seção em leitura.
Pode ser interrompida pela tecla Esc.

⌨️ Navegação por Teclado
Skip links para pular diretamente para a navegação ou conteúdo principal.
Totalmente utilizável sem mouse.

🏷️ Estrutura Semântica
Foram utilizados recursos como:

aria-labelledby
aria-live
aria-expanded
role="list"
role="listitem"
Botões com aria-label

Esses elementos melhoram a experiência de pessoas que utilizam tecnologias assistivas.

Estrutura do Conteúdo
O site foi organizado como uma sequência lógica de aprendizado:

🌱 Solo
💧 Água
🌾 Colheita
🌳 Floresta
📊 Dados do Paraná
♻️ Práticas Sustentáveis
🚀 Futuro
🤝 Ação do Cidadão

Cada seção apresenta uma parte da história, permitindo que o visitante compreenda como as escolhas feitas hoje influenciam o futuro do meio ambiente e da produção agrícola.

Tecnologias Utilizadas
HTML5

SVG Animado

Diferenciais
Identidade visual original baseada no conceito de ciclo sustentável.
Recursos de acessibilidade implementados de forma prática.
Compatibilidade com leitores de tela e navegação por teclado.
Conteúdo organizado em formato educativo e progressivo.
Integração entre sustentabilidade, tecnologia e cidadania.

Conclusão
O projeto Ciclo Vivo demonstra que campo, tecnologia e natureza não são áreas separadas, mas partes de um mesmo sistema. Por meio de informação acessível, recursos inclusivos e uma identidade visual coerente, o site busca conscientizar os visitantes sobre a importância da sustentabilidade para as gerações atuais e futuras.
